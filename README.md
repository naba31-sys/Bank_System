# 🏦 Bank System GUI

A simple Bank System application built with Python and Tkinter.

## 📌 Features

- Add a new account
- Show all accounts
- Search for an account
- Deposit money
- Withdraw money
- Delete an account

## 🛠️ Technologies

- Python
- Tkinter

## ▶️ How to Run

1. Make sure Python is installed.
2. Download or clone this repository.
3. Run:

```bash
python bank_gui.py
```

## 📚 About the Project

This project was created to practice Python programming and build a graphical user interface using Tkinter.
